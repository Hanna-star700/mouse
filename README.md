# Мишеняткові Знання

Інтерактивна дитяча гра для пізнання світу та вивчення обовʼязкових дат з історії України разом із мишеням Круть.

Візуал і анімації — в точному стилі сайту [Мишеняткова абетка](https://www.mousealphabet.com/):
- Фірмовий логотип: **Мишеняткові Знання**
- Небо, плавні хмари, пагорби
- Мишеня Круть у бульбашці звернення
- Блок підтримки проєкту («Підтримай знання»)
- Інтерактивна дорожня карта з фірмовими круглими пінами та ілюстраціями
- Партнери та фірмовий підвал

## Як запустити

Відкрий `index.html` у будь-якому браузері (подвійний клік).

Натисни кнопку **«Грати!»** або **«Поїхали!»**, щоб розпочати інтерактивну гру.
